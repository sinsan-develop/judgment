# calibration 92쌍의 맥락·후보 의미 검토 (2026-10-14)

판정: 원래 정답 ID를 제거한 92개가 전부 ‘정말 맞는 후보 없음’은 아니다. 어울의 별도 수동 검토에서 28개는 타당한 업무 후보가 남았고, 51개는 타당한 후보가 없으며, 13개는 판단 자료가 부족했다. 남은 타당 후보를 인정해도 기권이 많은 현상은 지속된다. 이 문서는 원본 라벨이나 기존 평가를 수정하지 않은 진단이다.

## 범위·검토 방법

- 대상은 calibration의 정답 제외 92개와 각각의 원래 정답 포함 92개: 합계 184개, 51연결 그룹. 원본 양성 365개 전체를 재검토한 결과가 아니다.
- 92쌍마다 현재 발화와 **저장된 과거 맥락 전체**를 읽고, 두 후보 집합의 합집합 6개에 대해 요청 대상·행위·조건을 검토했다. 과거 맥락 없는 입력도 그대로 검토했다. 미래 응답이나 final-test를 판단 근거로 사용하지 않았다.
- 판단표를 작성한 뒤 digest를 고정하고 기존 학습 전후 calibration logit를 결합했다. 후보 ID를 병합하거나 설명·입력·원본 gold·분할·점수를 수정하지 않았다. 새 모델 호출·학습·온도/임계값 조정은 없다.
- 원본 ZIP에는 XLSX 13개만 있고 공식적인 후보 의도 정의서·배타 경계는 없다. 관련 MAIN/SUB의 기존 확정 **train** 원본 사용례를 보조 근거로 확인했다. 라벨별 앞선 최대 5개 사용례는 관측 근거이며, 공식 정의나 의미 전체의 증명이 아니다.
- 모든 판정은 어울의 수동 의미 검토 v1이다. 도메인 담당자의 확정 라벨/인수 결과가 아니다. 사용례가 겹친다는 이유로 taxonomy 자체를 합치지 않았고, 자료로 구별할 수 없는 ID는 별도 미확정으로 기록했다.

## 유형과 타당 후보 기록

| 유형 | 판정 기준 |
|---|---|
| 유일한 정답 | 현재 후보 집합에 타당한 ID가 정확히 1개이고 추가 타당성 미확정 후보가 없음 |
| 복수의 타당한 답 | 현재 후보 집합에서 최소 2개 ID가 현재 요청·조건을 수용함. 일반·세부 범주의 배타 규칙은 근거 없이 가정하지 않음 |
| 정말 맞는 후보 없음 | 현재 발화의 대상·행위를 수용하는 후보가 없고 미확정 후보도 없음 |
| 문맥 부족 | 입력 맥락 또는 **후보 구분 정의** 부족으로 유일/복수/없음을 확정 못함. 이유와 잠정 ID를 기록하고 정답 지표 분모에서 제외 |

‘문맥 부족’에는 대화 맥락 자체가 없는 경우뿐 아니라, 맥락을 다 읽었어도 라벨 적용 범위가 자료에 없는 경우를 포함했다. 둘을 근거 문장에서 구별했다. 타당 ID(`valid_candidate_ids`)와 미확정 ID(`uncertain_candidate_ids`)는 별도이며, 미확정 ID를 오답이나 확정 정답으로 바꾸지 않았다. 확정 타당 ID가 이미 2개 이상이면 복수 유형은 확인됐으므로 유지하고, 추가 미확정 ID는 점수 범위에 반영한다.

## 의도 구분 기준 확인

다음은 **사용례와 현재 맥락에 근거한 검토 기준**이다. 공식 taxonomy 수정안이 아니다.

| 겹치는 의도 | 확인한 기준과 이번 처리 |
|---|---|
| 관광여가오락 요금 / 이용 금액 | 요금 사용례는 시간당 단가, 이용 금액은 누적 총액·정액제 비교였다. 시간당 비용 질문에서는 요금만 타당하게 기록. 단순 이름 유사로 동의 처리하지 않음 |
| 숙박 이용요금 / 금액 | 두 사용례 모두 숙박 가격 문의를 포함했다. 주말 객실 가격 사례에서는 둘 다 타당하되 ID를 각각 유지 |
| 포장가격 / 일반 가격 / 포장비 | 포장 음식 자체 가격은 포장가격·일반 가격에 해당. 포장비 사용례는 별도 용기·포장 수수료이므로 현재 음식 가격 질문에서 제외 |
| 가격 문의 / 가격문의 | 생활서비스의 공백 없는 ID는 train 사용례가 없어 배타 기준을 확인하지 못함. 공백만 보고 통합하지 않고 미확정으로 남김 |
| 제품가격 / 제품가격대 | 특정 물건의 정확한 값과 범위/가격대를 구별. 반복 어절 라벨의 적용 범위가 부족하면 미확정으로 기록 |
| 상품 재고 문의 / 상품 주문 | 존재·판매 여부 질문과 구체적인 구매 선택·수량 요청을 구별. 쿠키가 있는지 묻는 것을 쿠키 주문으로 바꾸지 않음 |
| 일반 주문 / 메뉴 추가 주문 | 첫 음료의 샷·크기 옵션 지정과 기존 주문 뒤 별도 메뉴 추가를 구별. 샷 추가라는 단어만으로 추가 메뉴 의도로 판정하지 않음 |
| 새 음식 포장 / 남은 음식 포장 | 추가 새 음식을 포장하는지 먹고 남은 부분을 싸는지 과거 맥락이 결정하지 못한 사례는 두 ID를 미확정으로 기록 |
| 피팅 / 피팅룸 규칙·위치 | 제품 착용 허락, 룸 사용 조건, 장소 질문을 구별. 현재 발화에 없는 화장/다른 사이즈 조건도 덧붙이지 않음 |
| 재건축 단계 / 시기·계획 | 사업 내용·확정 여부와 경과 연수·예정 시점을 구별. 장기간 지연을 확인하는 사례는 시기·계획이 타당하고 원래 단계 라벨은 현재 의도에 맞지 않는 것으로 검토 |

원본 MAIN에는 대화의 큰 주제가 여러 고객 발화에 이어지는 사용례가 있었다. 이번 검토는 엔진 질문인 ‘현재 발화의 의도’에 맞췄다. 예를 들어 할인 요청·사이즈 답변·포장 불필요 응답을 과거 대화의 가격 비교·제품 추천·빵 생산 시간으로 자동 유지하지 않았다. 이는 관측된 라벨 사용 방식과 현재 의도 계약 사이의 차이이며, 모든 원본 라벨이 잘못됐다는 판정이 아니다.

## 저장 점수 유형별 재집계

‘업무5 정확도’는 기권을 제외한 업무 후보 argmax가 **검토표의 타당 ID 중 하나**인지 계산한다. 실제 정답 응답은 6개 argmax가 그 집합에 속하는 경우다. 복수 유형의 순위는 타당 후보 중 최고 순위이며 원래 단일 gold 순위와 동일 지표가 아니다. 정답 없는 유형은 기권을 올바른 응답으로 센다. 문맥 부족에는 기권 수만 기술하고 정확도·정답 순위를 계산하지 않았다.

## 보존·검증·한계

- 원본 ZIP, group_map, 상속 anchor, calibration examples, 두 score, 기존 train_report, 기존 진단 summary·보고서, MODEL_CARD, 검토 입력/사용례 증거의 13개 파일을 조사 전후 SHA-256으로 대조해 변경 없음 확인.
- 92개 파생 전체와 대응 원본의 184개 ID 연결·후보 순서·입력/맥락 일치·원래 gold·유한 score·최상위 동률 없음 확인. 별도 정렬 계산으로 유형별 기권·업무 타당 선택·순위 분포를 재대조했다.
- 기존 정답 없는 92개 전체 기권 **80/92→78/92**는 그대로다. 이번 재집계는 새 검토 기준을 붙인 별도 진단이며 기존 calibration 457개 전체 결과나 final-test 결과를 대체하지 않는다.
- 표본은 51개 연결 그룹의 원본/파생으로 상호 의존한다. 표본수가 작은 유형에서 통계적 유의성·일반화·운영 품질 합격을 주장하지 않는다. 공식 정의서 부재와 수동 판단의 한계를 함께 유지한다.
- 원문·맥락·후보 ID·타당/미확정/부적합·근거·전후 점수는 `.work/semantic_review/review_table.private.json` 및 읽기용 Markdown에 저장했다. `criteria_evidence.private.json`에는 구분 기준별 train 사용례/MAIN/SUB를 보존했다. 모두 Git 제외다.
- 재현은 `docs/semantic_score_review.py`와 출력 없는 동반 notebook. 추가 학습·점수 생성·taxonomy 변경은 실행하지 않았다. 다음 검토 대상은 공식 라벨 경계와 미확정 사례의 도메인 판정이다.
